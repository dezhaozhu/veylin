# Compass 排产集成(本分支特有)

Veylin 本身是通用的 agent 桌面(上游文档见 [`architecture.md`](architecture.md))。**本分支在它之上做了一层排产工作台**:连接 Compass 排产后端,把多工厂数据、治理规则和排产认知做成一等公民。这份文档只讲这一层——上游那部分保持原样,不重复。

## 一句话架构

**一个 Compass 连接,项目决定看哪些工厂。**

```
Veylin(每人自己的实例)
  └── MCP 条目 "compass"  ← 只有地址 + 身份 token,不带场景信息
        └── 连接池按「项目的场景集」组出 x-compass-source 头
              └── Compass 后端(10.84.14.37:8000)→ guolu / shangzhong
```

关键设计:**MCP 条目只有一个**。以前是"一个工厂一个条目",加一个厂就多一个条目,还要手工配;现在场景是**授权参数**,项目决定这次会话能看哪些厂。加新厂 = 后端插一行授权,Veylin 侧十分钟内自动多出一个项目,条目数永远是 1。

## 起环境

```bash
git clone http://10.84.3.239:8081/gushirui/veylin.git
cd veylin && npm install
```

在 `apps/server/.env` 里加一行(token 找 gushirui 要,每人一份):

```
VEYLIN_COMPASS_IDENTITY={"url":"http://10.84.14.37:8000","token":"<你的账号 token>"}
```

```bash
npm run dev          # server :8787 + web(端口见输出)
```

**只需要这一行配置。** 启动时和之后每 10 分钟,对账器会去问后端 `/my/sources`,按你被授权的场景自动创建 MCP 条目和对应项目(锅炉厂、上重)。不用手工配 MCP,不用填场景。授权被收回时,对应项目自动停用(不删,历史钉定仍可解析)。

想连自己本机的 Compass 后端就把 url 换成 `http://127.0.0.1:8000`(后端起法见 compass 仓库的 `docs/DEVSETUP.md`)。

## 项目 = 数据源集合

侧边栏的"项目"是本分支的核心概念,不是文件夹:

- **默认项目**:按你的授权自动生成,一个场景一个(锅炉厂、上重)
- **自建项目**:点项目区的「+」,勾选若干数据源组合而成(比如同时选两个厂做对比)
- **会话钉定到项目后**,这条会话只能看到该项目的场景。钉在锅炉厂的会话,agent 拿不到上重的数据——这是**服务端授权层**挡住的,不是提示词约束
- 没钉项目的会话属于"个人区",拿不到任何分组 MCP

多场景项目里,agent 每次调工具都必须指明 `scene`;单场景项目省略即可。

## 场景认知卡

项目首页(点侧边栏项目名进入)显示每个数据源的**认知卡**:这个厂是什么排产结构、产能怎么定义、有哪些红线、数据有多少是真值/推断/猜测、规则健康度如何。多场景项目会合并成一张对齐的对比表,只有一侧有的行自动折叠。

卡片本身由 Compass 服务端渲染(MCP widget),Veylin 只是宿主——所以**将来接入别的能力(比如质量),它的卡会自动多出一列,Veylin 不用改代码**。

卡上每个区块有「这里不对?」:点了会在当前项目开一条会话,草稿引述卡片当前内容,你补一句哪里不对即可。修正走 Compass 的治理闭环(提案 → 影子验证 → 批准),不会直接改数据。

## 和上游的关系

本分支从 dezhao 的开源 Veylin 分叉而来,**表格子系统是永久分叉**:上游是自研表格,我们换成了 AG-Grid 企业版并深度接了排产(状态语义、主从展开、图表)。合并上游时的规矩:基座(聊天/桌面/服务端/可观测)取上游,表格子系统取我们的。

## 开发注意

- 服务端测试:`cd apps/server && VEYLIN_DATA_DIR=/tmp/vt-$$ node --import tsx --test --test-concurrency=1 "src/**/*.test.ts"`
- 前端:`cd apps/web && npm test && npm run typecheck && npm run build`
- **隔离相关的代码改动要格外小心**。项目钉定、连接池、溯源印记这三处经过多轮对抗评审,测试是承重的:比如"两个项目共用同一个工具键但表格印记必须不同且双向硬拒"这条,删掉守卫会有专门的测试失败。改这块前先读 `apps/server/src/mcp-scoping.ts` 和 `compass-pool.ts` 的模块注释。
